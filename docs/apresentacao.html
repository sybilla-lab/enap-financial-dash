Destaque técnico
Rendimentos
por projeto
Os extratos bancários registram rendimentos no nível da conta, sem discriminação por projeto. O sistema calcula automaticamente a atribuição proporcional usando o saldo corrente de cada projeto como base.
pct = saldo_projeto ÷ total_positivo_conta
rendimento_atribuído = líquido_mês × pct
  • Rendimento do último dia do mês → lançamentos do mês são incluídos
  • Projetos encerrados saem da base após a transferência do saldo
  • Reset de período na transição utilizado → disponível
